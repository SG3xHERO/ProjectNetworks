Built for Every Season

Project Launcher — the official way to play. One click to install, update, and jump in.

No more hunting for modpack files, configuring Prism Launcher, or chasing Discord messages for server IPs. Project Launcher is live. Sign in with your Microsoft account, pick the season pack, and hit play. Mods install automatically, the launcher keeps itself updated, and you can see who's online before you even launch.

  • Microsoft OAuth Login Play on your real account — secure, fast, no faff
  • One-Click Install & Update New season packs pushed by admins, received instantly
  • Server-Driven Manifest Admins manage packs remotely — no Discord file hunting
  • Auto-Updates Everything Launcher updates itself — always on the latest version
  • Smart RAM Management Per-pack RAM settings, recommended amounts per modpack
  • Live Server Status See who's online before you even launch

About

What is Project Networks?

Project Networks is my UK-based platform where I build, host, and share projects with the community. From free tools like the MOT Checker to game servers like Minecraft Season, everything here is designed to be useful, fun, and accessible.

It's a space to showcase what I'm working on — web apps, helpful tools, gaming servers, and now the Project Launcher. Each project is built with care and shared openly. Have ideas? Reach out!
